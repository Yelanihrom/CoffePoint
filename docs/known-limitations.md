# Известные ограничения

Проверено по рабочей копии на 20.10.2026. Эта страница фиксирует существующее
поведение; перечисленные пункты не исправляются одним обновлением документации.

| Область | Текущее ограничение | Что учитывать |
| --- | --- | --- |
| Аналитика продаж | `sales_analytics` с открытым концом проверен на тестовом и рабочем развертываниях | Используются текущие привязки терминалов к станциям, а не исторические; отчёт без терминала не приравнивается к нулевым продажам |
| Обновления Android | Публичные APK и `update.json` публикуются через Production release; подпись и целостность проверяются | Системная установка и разрешения зависят от устройства; см. [обновления](app-updates.md) |
| Каталог / удаление | Android отправляет `delete`, но в локальном `Router.gs` нет обработчика и `deleteEntity` | Успешное серверное удаление не проверено; в серверных тестах один `TODO` |
| Уведомления | Запускаются после успешного импорта; pending-изменения и ошибки импорта блокируют проверку | Редкое уведомление не обязательно означает отсутствие критичных остатков |
| Настройки уведомлений | В Android 1.0.25 подключены к рабочему серверу v27 | Применение на другом телефоне после импорта; правки одного флага разрешаются последней принятой отправкой, не общей серверной ревизией |
| Расписание | WorkManager зависит от сети и ограничений Android | Часовой период не является гарантией запуска ровно раз в час |
| Склад → станция | В снабженческом первом шаге фактический остаток и списание добавленного сохраняются одной Room-транзакцией; HTTP-запросы по-прежнему отдельные | Общей серверной транзакции и отката при частичном сетевом успехе нет |
| Повтор списания | Защита от повторного списания хранится в памяти ViewModel | Текущий повтор отправки защищён, восстановление после уничтожения процесса требует отдельной проверки |
| Конфликты | Есть сравнение временных меток, но нет ручного слияния | Импорт умеет снять блокировку с уже конфликтующих локальных записей и заменить их удалёнными |
| Параллельное обслуживание | Перед стартом добавлена загрузка актуальных данных, но сохранение ещё не проверяет исходную серверную версию | Другое устройство может изменить остатки после GET; полная защита от перезаписи пока не реализована |
| Импорт | Полный импорт обёрнут в Room-транзакцию; HTTP-чтение разных листов не является единым снимком | Для визитов подтверждение требует пары визит/начисление; глобального серверного snapshot нет |
| Заработок снабженца | Android 1.0.25 использует рабочий сервер v27; нужен один активный серверный снабженец | Чтение рабочего API проверено; live-запись визита/начисления не тестировалась. Потеря навигационной сессии может начать другой визит с новым UUID |
| Сотрудники | Для оператора выбирается первый активный сотрудник, для снабженца требуется единственный активный | Личного входа и выбора сотрудника ещё нет; без однозначного снабженца визит не сохраняется |
| Привязки | Сервер отклоняет пересечение разных операторов у одной станции в один день | Перед изменением назначений проверить периоды `validFrom`/`validTo` |
| Создание станции | Новый ID вычисляется как локальный максимальный ID + 1 | Независимое создание с нескольких устройств может дать совпадение ID |
| Удаление станции | Метод Android удаляет локальные записи; отдельного серверного удаления станции нет | Не считать его синхронизируемым удалением в Sheets |
| Камера | Модуль сохранён, обязательные фото отключены, текущего вызова загрузки из Android нет | Не удалять код камеры при чистке без отдельного решения |
| Авторизация | Общий токен приложения; права ролей задаются UI | Нет серверных пользователей и отдельных токенов сотрудников |
| Покрытие тестами | Проверены сетевые сценарии и серверные функции на имитациях | Нет полного покрытия UI, миграций Room, WorkManager и конкуренции устройств |
| Схема Room | `exportSchema=false` | Версионированные схемы и автоматические тесты всех миграций не заведены |
| Выпуски | Рабочие APK и `update.json` публикуются из тега `master` через workflow; Apps Script не публикуется через CD | Серверные изменения нужно опубликовать отдельно до выпуска зависимого APK |
| Тестовый стенд | HTTP-чтение и запись в копию проверены; тестовые триггеры, фото и отдельные терминалы не настроены | CI APK изолирован от рабочего API, команды реальным терминалам заблокированы; проверка сценария на телефоне выполняется отдельно |

При исправлении пункта обновить эту таблицу, соответствующее руководство
и регрессионный тест. Не оставлять описание ограничения после устранения.
