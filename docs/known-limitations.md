# Известные ограничения

Проверено по рабочей копии на 20.10.2026. Эта страница фиксирует существующее
поведение; перечисленные пункты не исправляются одним обновлением документации.

| Область | Текущее ограничение | Что учитывать |
| --- | --- | --- |
| Каталог / удаление | Android отправляет `delete`, но в локальном `Router.gs` нет обработчика и `deleteEntity` | Успешное серверное удаление не проверено; в серверных тестах один `TODO` |
| Уведомления | Запускаются после успешного импорта; pending-изменения и ошибки импорта блокируют проверку | Редкое уведомление не обязательно означает отсутствие критичных остатков |
| Сроки узлов | В уведомлениях снабженца и управляющего участвуют только миксеры и контейнер | Для остальных узлов уведомлений нет |
| Расписание | WorkManager зависит от сети и ограничений Android | Часовой период не является гарантией запуска ровно раз в час |
| Склад → станция | Сохранение станции и списание склада — разные локальные действия и HTTP-запросы | Общей транзакции с откатом на двух сущностях нет |
| Повтор списания | Защита от повторного списания хранится в памяти ViewModel | Текущий повтор отправки защищён, восстановление после уничтожения процесса требует отдельной проверки |
| Конфликты | Есть сравнение временных меток, но нет ручного слияния | Импорт умеет снять блокировку с уже конфликтующих локальных записей и заменить их удалёнными |
| Импорт | Станции/остатки/настройки заменяются последовательно, без общей Room-транзакции этого импорта | Успешный GET не гарантирует атомарное обновление всей локальной БД |
| Сотрудники | Заработок использует первого активного сотрудника | Личного входа и выбора сотрудника ещё нет |
| Привязки | Сервер отклоняет пересечение разных операторов у одной станции в один день | Перед изменением назначений проверить периоды `validFrom`/`validTo` |
| Создание станции | Новый ID вычисляется как локальный максимальный ID + 1 | Независимое создание с нескольких устройств может дать совпадение ID |
| Удаление станции | Метод Android удаляет локальные записи; отдельного серверного удаления станции нет | Не считать его синхронизируемым удалением в Sheets |
| Камера | Модуль сохранён, обязательные фото отключены, текущего вызова загрузки из Android нет | Не удалять код камеры при чистке без отдельного решения |
| Авторизация | Общий токен приложения; права ролей задаются UI | Нет серверных пользователей и отдельных токенов сотрудников |
| Покрытие тестами | Проверены сетевые сценарии и серверные функции на имитациях | Нет полного покрытия UI, миграций Room, WorkManager и конкуренции устройств |
| Схема Room | `exportSchema=false` | Версионированные схемы и автоматические тесты всех миграций не заведены |
| Выпуски | Ручная сборка и загрузка APK, отдельная публикация Apps Script | Версии кода на устройстве, в Git и на сервере могут расходиться |

При исправлении пункта обновить эту таблицу, соответствующее руководство
и регрессионный тест. Не оставлять описание ограничения после устранения.
