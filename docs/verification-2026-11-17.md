# Проверка правил обслуживания 17.11.2026

Ветка `test`, Room 42, TEST Apps Script v24. Рабочая таблица, production
deployment, `master`, теги и релизы в этой проверке не менялись.

## Автоматические проверки

- 132 JVM-теста: сетевые контракты, проверка шести правил, числа и границы.
- 96 Android instrumentation-тестов на эмуляторе: миграции 40/41→42,
  Room/pending, повтор отправки, конфликт, отмена запроса, конкурентная правка,
  переиспользованный экран и выбор узлов для уведомлений.
- 129 Node-проверок прошли; один прежний TODO по удалению каталога не покрыт.
- Проверены ссылки документации и отсутствие ошибок `git diff --check`.

## Реальный TEST-сервер

Проверка выполнена через Compose-форму и реальные репозитории/коннектор.
Использована временная сборка `ru.coffeepoint.livecheck.ci` с отдельной БД,
не обычный тестовый или рабочий пакет. Второй клиент — отдельная установка
этого пакета в Android-профиле 10 того же эмулятора, со своей БД и процессом.
Это проверка двух изолированных клиентов, не двух физических телефонов.

| Сценарий | Результат |
| --- | --- |
| Открытие настроек | С сервера импортированы шесть правил |
| Сохранение через форму | Миксеры: 30 дней / 0 продаж → 31 / 1; сервер подтвердил значения |
| Импорт вторым клиентом | В независимой БД получены 31 / 1; проверено достижение порога продаж |
| Сохранение без Wi-Fi и мобильных данных | В форме введены 32 / 2, Room сохранил pending с `CONNECTION`; экран показал сообщение о локальном сохранении |
| Независимое чтение сервера во время offline | В Sheets оставались 31 / 1 |
| Восстановление подключения | Без повторного сохранения общий `GoogleSheetsSyncWorker` завершился `SUCCEEDED`; pending очистился, сервер получил 32 / 2 |
| Повторный импорт вторым клиентом | Получены 32 / 2 |
| Восстановление тестового правила | Через репозиторий возвращены 30 / 0; создана новая версия `updatedAt`, старое время не подделывалось |

Другие правила, остатки, станции, визиты и финансовые операции намеренно
не изменялись. Временная сборка/профиль и тестовый код не входят в выпуск.
Снимки формы и логи сохранены локально в игнорируемой `.codex`; секреты
и авторизованные URL в отчёт не включены.

## Что ещё не проверено

- Интерфейс на двух физических телефонах и работа при длительных ограничениях
  батареи/Doze: проверка профилей этого не доказывает.
- Показ системного пуша именно вследствие живого изменения лимита: выбор узлов
  и уведомления проверены изолированными Android-тестами, не этим live-прогоном.
- Автоматического объединения конфликтующих правил нет: pending сохраняется,
  CONFLICT не обходится принудительной сменой времени.
- После этого TEST-прогона отдельно подготовлены рабочий лист и Apps Script v33:
  шесть правил и все 12 коллекций проверены read-only. Рабочие POST-изменения
  не имитировались; исходный TEST-прогон не считается их проверкой.
